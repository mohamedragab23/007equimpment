# نظام إدارة مخزون معدات طلبات - وكالة 007

نظام متكامل لإدارة توزيع المعدات على المشرفين والطيارين عبر المناطق، مع إدارة صلاحيات ومزامنة (لاحقاً) مع Google Sheets.

## تشغيل المشروع

### 1. الواجهة الأمامية (React + Vite)

```bash
npm install
npm run dev
```

ثم افتح: [http://localhost:5173](http://localhost:5173)

### 2. الـ Backend (Flask - للمصادقة والصلاحيات)

```bash
pip install -r requirements.txt
# من مجلد المشروع:
set FLASK_APP=api.app
flask run --port 5000
```

أو من مجلد المشروع مع Python:

```bash
cd d:\Download\007equimpment-main
$env:FLASK_APP="api.app"; flask run --port 5000
```

**ملاحظة:** تسجيل الدخول يعمل فقط عند تشغيل الـ Backend. المستخدم الافتراضي للتجربة:
- **اسم المستخدم:** `admin`
- **كلمة المرور:** `admin`

(غيّر كلمة المرور في الإنتاج؛ بيانات المستخدمين محفوظة في `data/users.json`)

## حل المشاكل الشائعة

### خطأ `net::ERR_NAME_NOT_RESOLVED` مع `*.supabase.co`

هذا الخطأ **ليس Bug داخل React غالباً**؛ معناه أن جهازك/الراوتر لا يستطيع عمل DNS Resolve للدومين.

- **تحقق سريع** (Windows PowerShell):

```powershell
nslookup llevzxkcuompyjqkzkdn.supabase.co
```

إذا كانت النتيجة مثل `Non-existent domain` أو لا يعطي IP، فالمشكلة DNS.

- **حلول عملية (بالترتيب)**:
  - غيّر DNS إلى `1.1.1.1` و `8.8.8.8` (أو DNS شركة الإنترنت إذا كانت تحجب).
  - نفّذ `ipconfig /flushdns` ثم أعد تشغيل المتصفح.
  - جرّب شبكة أخرى/Hotspot للتأكد أن المشكلة ليست من الراوتر.
  - عطّل VPN/Proxy إن كان موجوداً.

### المتصفح يشغل نسخة قديمة (Caching / Service Worker)

لو وجدت في الـConsole أنه يستدعي ملفات قديمة أو منطق قديم، قد يكون السبب Service Worker.
تم **تحسين** Service Worker في `sw.js` + تحديث طريقة التسجيل في `src/main.jsx`:
- في **التطوير**: يتم إلغاء تسجيل أي Service Worker لتجنب كاش قديم.
- في **الإنتاج**: يتم تفعيل Service Worker مع تنظيف الكاش القديم وتحديث تلقائي آمن.

- **تنظيف يدوي سريع**:
  - افتح DevTools → Application → Service Workers → Unregister
  - ثم Application → Storage → Clear site data

## ما تم تنفيذه (حسب المواصفات)

- **واجهة تسجيل الدخول:** اسم مستخدم / كلمة مرور، جلسات آمنة، تسجيل خروج تلقائي بعد 30 دقيقة عدم نشاط.
- **نظام الصلاحيات:** مسؤول، مدير مخازن، مدير حسابات، مشرف — مع إظهار/إخفاء الوحدات حسب الصلاحية.
- **شريط تنقل ديناميكي:** يظهر فقط العناصر المسموح بها للمستخدم.
- **وحدات:** لوحة التحكم، المشرفين والمناديب، المخزون الرئيسي، **مخزون الزونات** (عرض مجمع لكل منطقة)، الطلبات، إدارة الصلاحيات (للمسؤول فقط).
- **Backend:** Flask مع مسارات `/api/auth/login`, `/api/auth/logout`, `/api/auth/me`, `/api/auth/config`؛ إعدادات المناطق والوحدات من `api/config.py`.
